# Toyota Supra Performance Analysis

## Overview
This project analyzes the performance specifications
of Toyota Supra models across different generations.

## Models Analyzed
- A80 RZ (1997)
- A90 RZ (2019)

## Analysis
- Horsepower comparison
- Torque comparison
- Engine displacement comparison
- Horsepower growth rate

## Technologies
- Python
- SQLite
- SQL
- Pandas
- Matplotlib

## Project Structure
- data/: SQLite database
- src/: Python analysis scripts
- output/: Graphs and CSV results

## Key Findings
- Horsepower increased by approximately 21.43%.
- Torque increased from 451 Nm to 500 Nm.
- Engine displacement remained almost unchanged.

## Purpose
To practice database management, SQL queries,
data analysis, and visualization using Python.
